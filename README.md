# 智能学习伴侣 - AI个性化学习路径规划师

基于 LangGraph 多智能体架构的 AI 学习规划系统，支持自然语言对话、个性化学习计划生成、知识技能树拆解、多源资源推荐、测试题批改、学习进度追踪、学习时长记录、图片打卡等功能。

## 在线体验

**网站地址：** https://study-1498.onrender.com

## 技术栈

- **前端：** 纯 HTML/CSS/JavaScript（三栏布局，响应式适配手机端）
- **后端：** Python + FastAPI（RESTful API）
- **多智能体编排：** LangGraph（ReAct 自主决策模式）
- **大模型：** DeepSeek API（deepseek-chat 结构化输出 + deepseek-reasoner 高质量问答）
- **数据存储：** 浏览器 localStorage（对话/进度/测试/学习时长/图片，刷新不丢失）
- **部署：** GitHub + Render + UptimeRobot（免费托管，自动部署，定时保活）

## 多智能体架构

```
                    ┌─────────────────────┐
                    │  Supervisor Agent   │
                    │  （学习规划总监）    │
                    │  观察→思考→决策→循环 │
                    └─────────┬───────────┘
           ┌─────────────────┼─────────────────┐
           ▼                 ▼                 ▼
    ┌─────────────┐   ┌─────────────┐   ┌─────────────┐
    │  Planner    │   │ Researcher  │   │   Coach     │
    │ 任务拆分智能体│   │ 资源推荐智能体│   │ 计划调优智能体│
    └─────────────┘   └──────┬──────┘   └──────┬──────┘
                             │                   │
                    ┌────────▼────────┐   ┌─────▼─────┐
                    │  多源搜索工具集  │   │ ICS日历   │
                    │ B站/知乎/文档/GitHub│ │ 导出工具  │
                    └─────────────────┘   └───────────┘
```

### Agent 职责

| Agent | 角色 | 职责 |
|-------|------|------|
| Supervisor | 调度者 | 观察全局状态，自主决策下一步调用哪个 Agent |
| Planner | 课程拆解专家 | 拆解技能树，生成速成版/扎实版两套方案 |
| Researcher | 学习资源研究员 | LLM生成资源框架 + 多源搜索补全真实链接 |
| Coach | 学习教练 | 生成周计划（含艾宾浩斯复习节点），根据反馈动态调优 |

## 核心功能

### 1. 低门槛交互
- 6个预设目标模板，点击一键生成计划
- 自然语言输入，AI自动提取学情
- 学情卡片点选，不用打字
- 智能补全默认值，信息不足不追问
- 快捷操作栏：出题测试/调整计划/下一步学什么/记录学习/导出日历

### 2. 智能技能树拆解
- 大模型把学习目标拆解为层级化技能树
- 双方案生成：速成版 vs 扎实版，可切换
- 每个知识点标注难度、先修知识、建议学时
- 勾选已掌握知识点触发金色点亮动画

### 3. 多源学习资源推荐
- B站API真实视频链接
- 知乎搜索、官方文档、GitHub项目匹配
- 区分入门/进阶/实战材料
- 每个资源带可点击链接

### 4. 学习计划生成
- 按每日可用时间排定周计划
- 艾宾浩斯遗忘曲线复习节点
- 理论学习 + 实操任务划分
- 支持导出 ICS 日历文件导入手机

### 5. 智能测试系统
- 说"考考我"自动生成测试题
- 3道选择 + 2道简答，含答案解析
- 选择题精确匹配，简答题 LLM 批改
- 自动提取薄弱点，更新用户画像

### 6. 学习时长记录
- 对话输入"今天学了2小时"自动识别
- 内置计时器：开始/结束一键打卡
- 累计时长/本周学习/连续天数/7天柱状图
- 连续打卡徽章显示

### 7. 图片打卡
- 输入框相机按钮，支持拍照/相册选择
- 自动压缩到800px，对话内永久保存
- 记录笔记、做题情况等学习状况

### 8. 动态计划调优
- 用户反馈掌握情况，AI重新调整路线
- 薄弱点增加练习，已掌握知识点跳过
- 整体周期变化自动重新生成完整计划
- 调优后对比新旧计划，给出具体变化说明

## 手机端适配

- 底部固定 Tab 栏：聊天 | 学习路线
- 学习路线全屏展示，内部子 Tab 横向滚动
- 侧边栏抽屉式历史对话列表

## 本地运行

```bash
# 安装依赖
pip install -r requirements.txt

# 设置环境变量
set DEEPSEEK_API_KEY=你的API_Key

# 启动服务
uvicorn main:app --host 0.0.0.0 --port 8000

# 浏览器打开
http://localhost:8000
```

## API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/chat` | POST | 发送消息，返回AI回复和更新后的对话状态 |
| `/api/ics` | POST | 导出学习计划为ICS日历文件 |
| `/api/health` | GET | 健康检查 |
