# 智能学习伴侣 - AI个性化学习路径规划师

基于LangGraph多智能体架构的AI学习规划系统，支持自然语言对话、个性化学习计划生成、知识技能树拆解、多源资源推荐、测试题批改、学习进度追踪等功能。

## 技术栈

- **前端**：Streamlit + HTML/CSS
- **后端**：Python 3.x
- **多智能体编排**：LangGraph（ReAct自主决策模式）
- **大模型**：DeepSeek API（deepseek-chat + deepseek-reasoner）
- **数据存储**：浏览器localStorage（base64编码持久化）
- **部署**：Render + GitHub + UptimeRobot

## 多智能体架构

```
                    ┌─────────────────────┐
                    │  Supervisor Agent   │
                    │  （学习规划总监）     │
                    │  观察→思考→决策→循环  │
                    └──────────┬──────────┘
           ┌───────────────────┼───────────────────┐
           ↓                   ↓                   ↓
    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
    │ Planner     │    │ Researcher  │    │ Coach       │
    │ 任务拆分智能体 │    │ 资源推荐智能体 │    │ 计划调优智能体 │
    └─────────────┘    └──────┬──────┘    └──────┬──────┘
                               │                   │
                    ┌──────────┴─────────┐    ┌────┴────┐
                    │  多源搜索工具集     │    │ ICS日历  │
                    │ B站/知乎/文档/GitHub│    │ 导出工具  │
```

### Agent职责

| Agent | 角色 | 职责 |
|-------|------|------|
| Supervisor | 调度者 | 观察全局状态，自主决策下一步调用哪个Agent |
| Planner | 课程拆解专家 | 拆解技能树，生成速成版/扎实版两套方案 |
| Researcher | 资源研究员 | LLM生成资源框架 + 多源搜索补全真实链接 |
| Coach | 学习教练 | 生成周计划+艾宾浩斯复习，动态调优 |

## 核心功能

1. **对话式交互**：自然语言输入学习目标，AI自动提取学情信息
2. **双方案生成**：速成版（快速入门）/ 扎实版（稳扎稳打）
3. **技能树可视化**：阶段→知识点，含先修知识、难度分级、学时估算
4. **多源资源推荐**：B站真实视频链接 + 知乎文章 + 官方文档 + GitHub项目
5. **周计划排程**：按每日时长排程，标注理论/实操/复习
6. **艾宾浩斯复习**：学习后第1/3/7天自动插入复习节点
7. **测试题系统**：自动出题（3选择+2简答）、自动批改、错题记录
8. **进度追踪**：知识点勾选已掌握，进度环实时更新
9. **动态调优**：用户反馈后AI自动调整计划，显示具体变化
10. **记忆系统**：用户画像（薄弱点/强项/平均成绩）持久化保存
11. **日历导出**：生成ICS文件，可导入手机/电脑日历
12. **多对话管理**：每个学习目标独立对话，数据本地持久化

## 本地运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 设置API Key（环境变量或在侧边栏填写）
set DEEPSEEK_API_KEY=sk-你的key

# 3. 启动
streamlit run app.py
```

## 使用流程

1. 打开网站 → 点击"+ 新建对话"
2. 输入学习目标（如"7天速成高数"）
3. AI询问缺失的学情信息，或说"用默认设置"直接生成
4. 查看技能树、资源推荐、周计划
5. 学习过程中：
   - 勾选已掌握知识点
   - 说"考考我"做测试题
   - 说"下一步学什么"获取建议
   - 说"缩短为七天"调整计划
6. 下载ICS日历导入手机
7. 所有数据自动保存在浏览器本地

## 技术亮点

- **LangGraph ReAct模式**：Supervisor Agent自主决策，非固定流水线
- **工具调用**：Researcher Agent集成B站/知乎/官方文档/GitHub多源搜索
- **双模型策略**：结构化任务用deepseek-chat（快），普通问答用deepseek-reasoner（质量高）
- **阶段感知意图识别**：收集学情阶段优先识别学习目标，避免误判
- **localStorage持久化**：base64编码存储，刷新不丢失
